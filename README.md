# Решение систем линейных алгебраических уравнений (СЛАУ)

## Цель работы

Исследование точности и производительности численных методов решения систем линейных алгебраических уравнений:
- метода Гаусса
- метода Гаусса с частичным выбором ведущего элемента
- LU-разложения

---

## Реализованные методы

В рамках работы реализованы:

- Метод Гаусса без выбора ведущего элемента  
- Метод Гаусса с частичным выбором ведущего элемента  
- LU-разложение матрицы (без перестановок)  
- Прямая подстановка (Forward Substitution)  
- Обратная подстановка (Back Substitution)  

Дополнительно реализованы:
- Вычисление невязки решения  
- Вычисление относительной ошибки  
- Генерация случайных матриц и векторов  
- Генерация матрицы Гильберта  

---

## Структура проекта

- `Matrix` — класс матрицы и базовые операции  
- `Gauss` — реализация численных методов решения СЛАУ  
- `Generators` — генерация тестовых данных  
- `Experiments` — проведение численных экспериментов  
- `main.cpp` — запуск всех экспериментов  

---

## Эксперименты

### 1. Решение одной системы

Для матриц различных размеров измеряется время работы:
- метода Гаусса  
- метода Гаусса с выбором ведущего элемента  
- LU-разложения  

Отдельно измеряются:
- время разложения LU  
- время решения системы через LU  

---

### 2. Несколько правых частей

Рассматривается задача решения системы с одной матрицей и несколькими правыми частями.

Сравниваются:
- многократный запуск метода Гаусса  
- LU-разложение + повторное решение  

Цель — показать эффективность LU-разложения при повторных вычислениях.

---

### 3. Матрица Гильберта

Исследуется численная устойчивость методов на плохо обусловленной матрице.

Используется:
- точное решение: `x = (1, ..., 1)`  
- правая часть: `b = Hx`  

Для методов вычисляются:
- невязка  
- относительная ошибка

## Основные выводы

- Метод Гаусса без выбора ведущего элемента является численно неустойчивым  
- Метод Гаусса с выбором ведущего элемента значительно повышает устойчивость решения  
- LU-разложение эффективно при решении нескольких систем с одной и той же матрицей  
- Для матрицы Гильберта наблюдается быстрый рост ошибки при увеличении размера  
- При больших размерах плохо обусловленных матриц методы могут терять точность или давать некорректные результаты  

---

## Замечания

- Все эксперименты проводятся с фиксированными seed для воспроизводимости результатов  
- Время измеряется с использованием `std::chrono`  
- В случае численной неустойчивости возможны ошибки выполнения или потеря точности
